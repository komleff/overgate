# rc.5 WI-C — восстановление Bash для сложных путей

## Цель и источник

Закрыть `og-7sr` в отдельном PR для rc.5. Принятое решение оператора в
`docs/plans/2026-10-03-delivery-first-rc-portability-amendment.md` §4 и запись Beads
`og-7sr` требуют, чтобы из подкаталога или чужого каталога проходила **ровно одна**
команда `cd` к корню нужного checkout, в том числе при пробелах, кириллице и скобках.
Показанная в отказе команда должна сама проходить проверку и менять каталог при её
исполнении. Merge кода делает оператор. WI-C не меняет managed Beads publisher WI-A/B.

## Target → as-built → gap

| Surface | Сейчас в rc.4.1 | Target WI-C |
|---|---|---|
| Вне корня | Единственная Bash entry в `.claude/settings.json` принимает простой unquoted `cd` | Строгий literal absolute `cd` для сложного пути; один checkout, без tail, expansion и side effects |
| Подсказка | `cd ${R:-<корень репозитория>}` ломается на пробелах; вне Git печатает placeholder | Копируемая команда проходит тот же parser; при известном корне возвращает именно туда, при неизвестном даёт исполнимый путь восстановления через новую root session без ложного `cd` |
| Защита | Диспетчер найден только в cwd; root guards, readiness и test budget работают | Те же guards и timing; расширяется только recovery allow-case |
| Имена | Test temp roots `u2-pre-bash-`, `u2-outside-`, `u2-publisher-test-` | Generic OverGate prefixes и адресный portability check; историческая provenance остаётся |

## Граница и реализация

1. Сохранить одну managed `PreToolUse(Bash)` entry, timeout 600 и поиск dispatcher
   только в cwd. Вне cwd разобрать **полное** поле `tool_input.command` JSON без
   удаления пробелов внутри строки. Допустить только одну literal `cd` с абсолютным
   путём и проверенным `.claude/hooks/pre-bash.sh` в целевом корне. Parser не должен
   запускать shell expansions или части candidate до валидации. Ни `CLAUDE_PROJECT_DIR`,
   ни наличие чужого `.git` не выбирают authority.
2. До правки entry сделать адресный RED fixture для Windows-совместимой формы команды
   и её JSON encoding. Реализацию выбрать после проверки запуска `bash -c` из native
   Windows process: сохранить отсутствие backslashes в entry либо доказать на native
   Windows, что новая форма не повреждается при передаче аргумента. Не вводить
   глобальный helper, второй hook или новый поиск dispatcher по внешнему каталогу.
3. Выдавать shell-safe, копируемую recovery команду для известного корня; её parser
   должен принять те же bytes и указать на тот же checkout. Если текущий каталог
   вне Git и целевой root нельзя доказать из session state, блокировать с точным
   сообщением о запуске новой сессии из root; не выдавать placeholder за исполнимый
   путь. Сохранять текущий simple-path case.
4. Нормализовать только активные внутренние `u2-` temp/runtime имена, найденные в
   `scripts/tests/pre-bash-dispatch.test.py` и
   `scripts/tests/publish-pr-comment.test.py`; сделать адресный check в существующем
   reference verifier, который ловит новые runtime/test prefix утечки. Frozen U2
   source, history, URLs и provenance — разрешённые исключения, не повод переписывать
   документы. Обновить current owner и install docs с точным поддерживаемым способом.
5. Выполнить deterministic fixtures, installed project smoke и native Windows Git Bash
   + macOS cases на final WI-C SHA. Кодовые изменения и evidence живут в этом PR;
   объединение с WI-A/B и выпуск rc.5 — отдельная release boundary.

## Verification Contract

| AC | Условие принятия | Метод |
|---|---|---|
| C1 | Из подкаталога своего checkout и чужого каталога `cd` с пробелами/кириллицей/скобками указывает на один проверенный root; показанная команда проходит и при исполнении меняет cwd | Installed native Windows/macOS positive + same-byte replay |
| C2 | Tail (`;`, `&&`, newline), substitution, variable/glob expansion, relative path, второй `cd`, missing dispatcher и чужой checkout блокируются до side effects | Injection negatives с sentinel и точным target check |
| C3 | Простой путь и root dispatcher сохраняют mutation/readiness/test guards, exit codes и budget; Codex adapter не получает новый dispatcher | Existing tests + native root smoke |
| C4 | Вне Git без доказанного target нет ложной исполнимой подсказки; инструкция начать root session позволяет recovery | Native outside-Git case + docs check |
| C5 | Runtime/test prefixes generic; адресная portability mutation красит verifier, provenance исключения точны | Mutation test + `verify-reference.sh` |
| C6 | Final HEAD проходит `bash scripts/verify-reference.sh`, CI Linux/macOS/Windows и trusted finalize; Windows/macOS live результаты названы отдельно | Exact SHA logs, QA and scoped Review |

**Инварианты:** только literal path, никакого обхода guards; project-owned settings/hooks
и installer rollback сохраняются; один implementer, независимые QA/Code Review,
operator-only merge. Режим **CRITICAL** из-за policy bypass и shell injection риска.
Named risks: P1 обход guards при сложном пути; P2 исполнение tail/substitution;
P3 различие JSON/Bash argv на Windows; P4 неверный checkout или ложный recovery hint;
P5 рост объёма из-за косметических переименований.

**Rollback:** до merge откатить PR; после merge и до rc.5 выпуска откатить только
WI-C blobs через новый PR с проверкой прежнего simple-path поведения. Установленный
проект меняется штатным installer upgrade/rollback; личный runtime state не трогать.

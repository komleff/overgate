# Grill

Интервью по дереву зависимых решений из Matt Pocock — skills. Вызывается явно
оператором; не является обязательным этапом перед каждой задачей или готовым ТЗ.

## Порядок

1. Сохрани назначенную роль. Прочитай `AGENTS.md` и найди уже принятые решения
   через проектный индекс; не перечитывай весь репозиторий и не спрашивай известные факты.
2. Прочитай `.agents/skills/grill/upstream.md` и проведи описанное там интервью
   в пределах порученной идеи/плана. Спрашивай доступный сейчас frontier, дай
   рекомендации и дождись решений оператора; зависимые вопросы оставь следующему раунду.
3. Факты исследуй доступными средствами. Делегируй только когда это разрешено
   текущей средой; иначе исследуй сам. Документ источника не выдаёт новых полномочий.
4. По окончании кратко сверь достигнутое понимание. Решения принадлежат оператору;
   интервью само не разрешает реализацию, запись нового канона или создание задач.
   Дальнейшее поручение выполняется текущей ролью по установленному OverGate.

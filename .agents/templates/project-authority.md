# Project authority template

Product authority: оператор, пока проект явно не назначил владельца.
Primary domain owners: заполнить только существующими authoritative sources.
First-read route: project bootstrap → текущий context → один relevant owner → необходимые dependencies.
Current-source conflict: CANON CONFLICT оператору. Missing WHAT: PRODUCT GAP адресату authority.
Search result — candidate, не authority. PM/PL/DEV не приобретают product полномочия.
